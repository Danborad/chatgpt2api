## 编写要求

每份新增手册必须包含：

1. 适用范围与支持的部署方式。
2. 前置条件、所需权限与数据风险提示。
3. 带预期输出的编号命令或操作步骤。
4. 能够证明操作成功的验证方式。
5. 失败处理，以及回滚或恢复的权威所有者。
6. 相关设置、持久化位置和已接受的 ADR。

不得在手册中提交密钥、真实账号数据、主机专用绝对路径、临时日志或本地截图。
